# Turing's Last Cipher - Game Design Document

## Game Overview
"Turing's Last Cipher" is a browser-based, puzzle-driven narrative game. Set in a retro computing terminal interface, the player takes on the role of a cryptanalyst deciphering a hidden archive of messages left by Alan Turing.

## Core Gameplay Loop
1. **Receive Message**: The player receives an encrypted text and a brief narrative context out of the archive.
2. **Analyze**: Use in-game tools (frequency analysis, cipher wheels, ADA assistant) to find patterns.
3. **Decipher**: Input the correct decryption parameters or plaintext.
4. **Discover**: Unlocking the message advances the story and provides the cipher key/concept for the next chapter.

## Target Audience
- Puzzle enthusiasts and alternate reality game (ARG) fans.
- Players interested in history, cryptography, and computer science.
- Casual browser gamers looking for an intellectual challenge.

## Game Objectives
- Solve 8 increasingly difficult cryptography puzzles.
- Uncover the true nature of the archive and "ADA".
- Learn fundamental coding and encryption techniques.

## Puzzle Progression
1. **Chapter 1**: Caesar Cipher (Shift substitution)
2. **Chapter 2**: Atbash Cipher (Reverse alphabet)
3. **Chapter 3**: Vigenère Cipher (Polyalphabetic substitution)
4. **Chapter 4**: Binary & Hexadecimal Translation
5. **Chapter 5**: Morse Code with Noise Interference
6. **Chapter 6**: Playfair Cipher
7. **Chapter 7**: Simulated Enigma Machine (Simplified)
8. **Chapter 8**: The Turing Test (Logic puzzle / AI dialogue interaction)

## Difficulty Curve
- **Chapters 1-2**: Tutorial phase. ADA assistant provides heavy hints.
- **Chapters 3-5**: Intermediate. Players must combine two techniques or filter out noise.
- **Chapters 6-8**: Advanced. Multi-step deciphering requiring the notebook feature.

## Scoring System
- **Time Bonus**: Solving within optimal time.
- **Hint Penalty**: Using ADA for hints reduces the chapter score.
- **Accuracy**: Minimal incorrect attempts yield a higher rating.

## Achievement System
- *First Crack*: Solve the first puzzle.
- *Blind Decrypt*: Solve a puzzle without using ADA.
- *Speed Demon*: Decrypt a message in under 60 seconds.
- *The Imitation Game*: Complete the final chapter.

## Replayability Features
- Time trial modes.
- Procedurally generated ciphertexts for post-game puzzles.
- Hidden "Ghost" messages that require specific deciphering patterns to uncover.
